Social Media Manager — MVP

Scope (MVP):
- Content calendar (day/week/month views)
- Post composer (drafts, images, link preview)
- Scheduling + multi-account posting

Tech stack:
- Frontend: React
- Backend: Node (Express)
- Database: PostgreSQL

Getting started (backend):
1. cd server
2. copy .env.example to .env and set DATABASE_URL
3. npm install
4. npm run dev
